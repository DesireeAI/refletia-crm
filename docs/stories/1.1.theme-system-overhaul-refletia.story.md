# Story 1.1: Theme System Overhaul - Refletia Color Palette

**Status:** Draft  
**Epic:** REFLECT-001 - Rebranding Complete - Twenty to Refletia Transformation  
**Created:** 2026-02-16  
**Created By:** @sm (River)  
**Executor:** @ux-design-expert  
**Quality Gate:** @dev  

---

## User Story

As a **user of the Refletia CRM**,  
I want **the entire visual theme to reflect Refletia's brand colors**,  
So that **the application feels cohesive with the new brand identity and provides an immersive user experience**.

---

## Story Context

**Existing System Integration:**
- **Integrates with:** `packages/twenty-ui/src/theme/constants/` theme system
- **Technology:** React 18 + TypeScript + Emotion + Radix UI Colors
- **Follows pattern:** Existing dual theme (light/dark) with 40+ configuration files
- **Touch points:** MainColorsLight.ts, MainColorsDark.ts, SecondaryColors*, ThemeContextProvider

**Brand Requirements:**
- **Primary Colors:** #521262 (Azul Escuro), #edb069 (Rosa Vibrante), #e2ab2a (Amarelo Dourado)
- **Secondary Colors:** 12 additional Refletia colors for complete palette
- **Accessibility:** WCAG AA compliance required for all color combinations
- **Theme Modes:** Maintain existing light/dark dual theme support

---

## Acceptance Criteria

### Functional Requirements:
1. **Refletia color constants implemented** in MainColorsLight.ts and MainColorsDark.ts
2. **15-color palette fully mapped** to existing theme structure
3. **Light and dark theme variants** created for all Refletia colors
4. **Theme integration working** with existing ThemeContextProvider
5. **Color contrast validation** passing WCAG AA standards

### Integration Requirements:
6. **Existing Twenty theme colors** remain accessible for fallback comparison
7. **All components using theme system** automatically inherit Refletia colors
8. **Theme switching functionality** preserved (light/dark toggle)
9. **CSS variable fallbacks** updated for performance optimization
10. **No breaking changes** to existing theme consumption patterns

### Quality Requirements:
11. **Automated contrast tests** implemented for all color combinations
12. **Visual regression tests** created for theme changes
13. **Documentation updated** with Refletia color specifications
14. **Code follows existing patterns** in twenty-ui theme structure
15. **Performance impact <5%** on theme loading and switching

---

## Technical Notes

**Integration Approach:**
- **Extend existing pattern:** Add REFLETIA_COLORS_* constants alongside existing MAIN_COLORS_*
- **Maintain compatibility:** Keep existing color names for backward compatibility
- **Theme provider:** No changes needed to ThemeContextProvider architecture
- **CSS variables:** Update CSS custom properties for fallback support

**Existing Pattern Reference:**
- **File structure:** Follow `packages/twenty-ui/src/theme/constants/MainColorsLight.ts` pattern
- **Naming convention:** Use existing Radix UI + custom color naming
- **Export pattern:** Maintain existing export structure in theme/index.ts

**Key Constraints:**
- **Must maintain** existing light/dark theme architecture
- **Cannot break** existing component theme consumption
- **Accessibility compliance** mandatory for production deployment
- **Performance impact** must be minimal (<5% overhead)

## Tasks / Subtasks

### Phase 1: Color Constants Implementation
1. **Create Refletia color constants** in packages/twenty-ui/src/theme/constants/
   - Create REFLETIA_COLORS_LIGHT object with all 15 colors
   - Create REFLETIA_COLORS_DARK object with dark variants
   - Map colors to existing naming conventions [Source: architecture/project-analysis-refletia.md#Theme System Architecture]

2. **Update MainColorsLight.ts** 
   - Replace existing colors with Refletia palette (AC: 1)
   - Maintain existing export structure and naming patterns
   - Add comments with color purposes and accessibility notes

3. **Update MainColorsDark.ts**
   - Create dark variants of all Refletia colors (AC: 1, 3)
   - Ensure proper contrast ratios for dark mode
   - Test visibility and readability in dark theme

### Phase 2: Secondary Colors Integration
4. **Update Secondary Colors files** if needed
   - Map remaining Refletia colors to secondary color structure
   - Ensure all 15 colors are available in theme system (AC: 2)
   - Validate color naming consistency

5. **Update theme index.ts exports**
   - Add Refletia color exports to main theme index (AC: 4)
   - Maintain backward compatibility with existing exports
   - Test import patterns from consuming components

### Phase 3: Integration and Testing
6. **Implement contrast validation tests**
   - Create automated WCAG AA contrast tests (AC: 5, 11)
   - Test all color combinations in both light/dark modes
   - Generate contrast ratio reports for documentation

7. **Update CSS custom properties**
   - Add CSS variables for Refletia colors (AC: 9)
   - Ensure fallback mechanisms work without JavaScript
   - Optimize for performance and loading speed

8. **Visual regression testing setup**
   - Create screenshot comparison tests for theme changes (AC: 12)
   - Test component rendering with new colors
   - Validate responsive behavior with new theme

### Phase 4: Documentation and Validation
9. **Update theme documentation**
   - Document Refletia color palette and usage guidelines (AC: 13)
   - Add accessibility compliance information
   - Create migration guide from Twenty to Refletia colors

10. **Performance validation**
   - Measure theme loading and switching performance (AC: 15)
   - Ensure <5% impact compared to current theme system
   - Optimize any performance bottlenecks found
