# Story 1.2: Brand Elements Replacement - Twenty to Refletia

**Status:** Draft  
**Epic:** REFLECT-001 - Rebranding Complete - Twenty to Refletia Transformation  
**Created:** 2026-02-16  
**Created By:** @sm (River)  
**Executor:** @dev  
**Quality Gate:** @dev  

---

## User Story

As a **user accessing the Refletia CRM**,  
I want **all textual references and visual branding to reflect the Refletia identity**,  
So that **the application presents a cohesive brand experience from the moment I open it, with no remnants of the previous Twenty branding**.

---

## Story Context

**Existing System Integration:**
- **Text Elements:** `index.html` (title, meta tags), `manifest.json` (app name, short name)
- **Visual Assets:** 80+ icons in `/public/images/icons/` (Windows, Android, iOS platforms)
- **Brand Touch Points:** Browser tabs, mobile homescreens, PWA installations, social sharing
- **Integration Pattern:** Static assets and HTML meta tags consumed by browsers and platforms

**Brand Requirements:**
- **Application Name:** "Refletia" replacing "Twenty" in all contexts
- **Meta Information:** Updated Open Graph, Twitter Card, and SEO metadata
- **Icon Assets:** Complete replacement of all platform-specific icons with Refletia branding
- **Cross-Platform Consistency:** Uniform brand presentation across Windows, Android, iOS, and Web

---

## Acceptance Criteria

### Text Element Updates:
1. **Application title updated** to "Refletia" in index.html
2. **Meta tags updated** with Refletia branding (Open Graph, Twitter Cards)
3. **Manifest.json updated** with Refletia name and short_name
4. **SEO descriptions updated** to reflect Refletia brand messaging
5. **Browser tab titles** showing "Refletia" instead of "Twenty"

### Icon Asset Replacement:
6. **All Windows icons replaced** (50+ files in windows11/ directory)
7. **All Android icons replaced** (6 files in android/ directory)
8. **All iOS icons replaced** (20+ files in ios/ directory)
9. **Favicon updated** for browser tab display
10. **PWA installation icons** updated with Refletia branding

### Brand Consistency:
11. **Social sharing cards** updated with Refletia branding
12. **App store descriptions** consistent with Refletia identity
13. **Platform-specific guidelines** followed for each icon format
14. **Asset optimization** maintained for performance (file sizes, formats)
15. **Fallback mechanisms** preserved for asset loading failures

## Technical Notes

**Text Element Locations:**
- **index.html:** `<title>`, meta tags, social sharing metadata
- **manifest.json:** `name`, `short_name`, description fields
- **Social Cards:** Open Graph and Twitter Card meta tags

**Icon Asset Structure:** [Source: architecture/project-analysis-refletia.md#Brand Elements Location]
```
packages/twenty-front/public/images/icons/
├── windows11/     # 50+ Windows icons (multiple sizes)
├── android/        # 6 Android icons (adaptive launcher)
└── ios/           # 20+ iOS icons (universal, app store)
```

**Asset Requirements:**
- **Formats:** PNG (raster), SVG (vector where supported), ICO (favicon)
- **Sizes:** Platform-specific requirements (16x16 to 1024x1024)
- **Optimization:** Compressed for fast loading without quality loss
- **Naming:** Maintain existing file naming conventions

**Integration Constraints:**
- **No breaking changes** to asset loading patterns
- **Maintain performance** of asset loading and caching
- **Cross-platform compatibility** for all icon formats
- **PWA functionality** preserved with new icons
